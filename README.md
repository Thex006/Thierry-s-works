# Thierry's works

Agency demo sites that live as folders in this repo. Each folder is its own Vercel project (Root Directory = the folder).

- `jogobella/` — Jogobella flavour slider with 3D bottles and fruit. Concept demo, not affiliated with Jogobella or Zott. Single self-contained `index.html`; `source/` holds the asset pipeline. Run locally with `node server.js`.
- `handyman-3d/` — Handyman in Columbus, premium 3D concept: photo-scanned tools knolled on a plywood bench, scroll-driven. Next.js static export. Run with `npm install && npm run build && npm start` (port 3008).
