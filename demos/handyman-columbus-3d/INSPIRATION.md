# Inspiration: Columbus handyman demo (3D)

Same page as the 2D demo, with a 3D hero: an open tool box (hammer, wrench, screwdriver) rendered in the
page's pine green. Made with the design kit's product renderer and shipped as still images: no live WebGL,
so it loads fast and works the same on phones.

## Sources and what I took
- **motionsites.ai, "Virtual Store"** (3D e-commerce): real objects set on a plain light ground, big and
  centred, as the hero. Taken: the one large object on the page's own ground, no panel or box around it.
- **motionsites.ai, "Protein Bars"** (food): the product shown whole with soft studio light and a floor
  shadow. Taken: the soft shadow and the satin finish, so the box looks solid, not flat.
- Not taken: the particle and shader heroes ("Flower Valley", "Particle Brain"). They're heavy on phones
  and say nothing about repairs. The prompts themselves are paid; I used only the free previews for ideas.

## Why a tool box
It says "handyman" before a word is read, and it uses the client's green. A real photo of their own kit
would beat it; the 2D version stays photo-led for that reason.
