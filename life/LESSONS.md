# Lessons (one line each, newest first)
- 2026-11-22: Set state.json `activity` at the START of every step, never only at the end; a stale "waiting" banner misled Thierry for hours.
- 2026-11-22: Look at every photo at full size before using it: a Commons "house with porch" file was the back of a postcard.
- 2026-11-22: Worker can't `git reset`; never `git add -A` a demo folder (the gate's Chrome profile lives in .taste-skill/). Add files by path.
- 2026-11-22: GitHub's "💎 Bounty" label search is mostly spam/farm repos; only fresh issues (<5 comments) on real projects are worth a look.
- 2026-11-22: Small-business sites often hide emails behind Cloudflare email protection; WebFetch shows "[email protected]", so read those in Chrome.
